# Hi, I'm Jenish 👋

Platform & SRE engineer turned founder. I build infrastructure, break it on purpose, and study how people (and agents) fix it.

## Now

**Co-founder at [Scenr.io](https://scenr.io)**

Scenr.io builds real broken environments on demand and drops engineers into them. What someone does inside a live incident tells you more about their actual capability than any interview or synthetic challenge ever could.

- Designing the control plane that provisions, breaks, observes, and verifies isolated cloud labs on demand
- Building an incident corpus sourced from real production outages, with rubrics and verifiable evaluation reports
- Working on the space where AI meets infrastructure: how humans and AI agents perform when production is on fire

> *Engineering skills, verified through real work.*

## Before Scenr.io

**Platform / SRE at FamPay**

- Owned CI/CD for 40+ microservices running on EKS with GitLab CI and ArgoCD (GitOps)
- Event-driven autoscaling with KEDA
- Hardened CI runner security using IRSA and OIDC based short-lived credentials
- Built Batch CSV processing feature into admin panel for merchant profile updates
- Built and Operated Ephemeral Environments to provision per engineer isolated testing environment.

## Things I love talking about

Distributed systems, infrastructure engineering, systems design, reliability, and what changes when AI agents start operating production systems.
